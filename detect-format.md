# Detect format (LeCheck)

Answer in exactly this layout. Do not add anything else. Do not write an email or a send-back message.

**Light: RED** or **Light: GREEN**

**Item status**
One line covering all five rubric items, in order, each as fine, red, check manually, or not applicable (with the reason). Example: "1 fine; 2 red; 3 fine; 4 not applicable (not survey data); 5 red". Every item must appear.

**Findings**
One entry per red item, in item order. Write "None." if there are no red items. For each entry:
- Item: [item name from the rubric]
- Quote: "[exact text of the first occurrence]" (or "No statement found" and where you looked)
- Other occurrences: list every further occurrence of the same problem, one entry each, giving the first few words of the sentence or table row in quotation marks. Do not stop at a fixed number. If there are none, write "None found". For absence items, write "Not applicable".
- Calculation (item 5 only): one line for each occurrence, in the form "[count] / [denominator] = [x]% (reported [y]%)". The denominator is the group size stated in the text, tables or captions for that group.
- Why it matters: [one short sentence]

**Check manually**
One line per uncertain item with the reason. If none, write "None." For Item 5 only, include the calculation.

**Scope**
Always end with this line: "This screening detects basic reporting issues from a fixed list. It does not assess whether the analysis or conclusions are correct."
