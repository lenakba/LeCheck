# Output format

Always answer in exactly this layout. Do not add anything else.

**Light: RED** or **Light: GREEN**

**Flags**
One entry per rubric item, not per occurrence. For each red item:
- Item: [item name from the rubric]
- Quote: "[exact text of the first occurrence]" (or "No statement found" and where you looked)
- Other occurrences: write at most three entries. Each entry is the first few words of the sentence or table row. If there are more than three, end with ‘and possibly more’ and do not list any further.
- Why it matters: [one short sentence]

In the send-back message, write one numbered point per item (not per occurrence). Each point states the instruction, gives the first quote, and adds: "The same issue appears elsewhere, so please check all instances (found: [the list])." If there are no other occurrences, leave that sentence out.
Exception for absences: for "Number of participants missing" and "Response rate missing", report the item once for the whole section. Write "No statement found" as the quote, do not list other occurrences (write "Not applicable" on that line), and in the send-back message leave out the sentence "The same issue appears elsewhere...".

**Check manually**
One line per uncertain item with the reason. If none, write "None."

**Send-back message**
Only if the light is RED. A short, polite message the reader can paste into an email, with one numbered point per flag, using the send-back wording from the rubric. If the light is GREEN, write "Not needed."
Write each numbered point as an instruction starting with a verb, without ‘Please’. List no more than three occurrences in the email.
Start the email with the following text, copied exactly: "These results were screened with a standardized AI-tool, and the AI flagged these issues. Before I read it, please:"
End the email with the following line, copied exactly: "Screened in GPT UiO with a language model approved for red data under UiO's data classification."

**Scope**
Always end with this line: "This screening detects basic reporting issues from a fixed list. It does not assess whether the analysis or conclusions are correct."
